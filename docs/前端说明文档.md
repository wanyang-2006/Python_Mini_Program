# 前端说明文档 — AI 答题闯关小程序（Phase 4B）

> 版本：v1.0 | 日期：2026-11-12 | 阶段：Phase 4B（Taro 框架搭建 + HTML 原型迁移）

## 一、阶段定位

本文档记录 Phase 4B 的产出：将 Phase 4A 的 HTML 单页原型迁移到 Taro 4.x + React 18 + TypeScript 框架，构建可在微信开发者工具中静态预览的小程序前端骨架。

- **当前状态**：5 个页面视觉骨架完成，编译通过，使用 mock 数据
- **不含**：API 联调（Phase 5）、用户登录（Phase 6）
- **下一步**：Phase 5 接入后端真实接口

## 六、状态管理（Zustand）

文件：`src/store/quiz.ts`

### Store 数据结构

```typescript
interface QuizState {
  topic: string               // 用户输入的学习主题
  sessionId: string | null    // 会话 ID（Phase 5 由后端返回）
  questions: Question[]       // 5 道题目
  currentIndex: number        // 当前题目索引（0-4）
  answers: AnswerRecord[]     // 已提交答案列表
}
```

### Question 类型

```typescript
interface Question {
  id: number
  content: string
  options: string[]       // ['A. xxx', 'B. yyy', ...]
  optionKeys: string[]    // ['A', 'B', 'C', 'D']
  correctAnswer: string   // 'A' | 'B' | 'C' | 'D'
  explanation: string
  tags: string[]
}
```

### 核心 Actions

| Action | 触发时机 |
|--------|---------|
| `setTopic(topic)` | 首页点击开始闯关 |
| `initSession(id, questions)` | Phase 5 替换为 API 响应；当前 mock 初始化 |
| `submitAnswer(record)` | 用户选择选项后 |
| `nextQuestion()` | 点击"下一题" |
| `reset()` | 报告页点击"再来一关" |

### MOCK_QUESTIONS

`store/quiz.ts` 内置 5 道 Python 基础单选题，用于 Phase 4B 静态预览。Phase 5 中 `initSession` 将由后端接口响应替代，不改动 store 结构。

## 七、页面导航流程

```
首页 (tabBar)
  └─ [开始闯关] navigateTo → 闯关页
                              └─ [查看报告] navigateTo → 报告页
                                                          └─ [再来一关] switchTab → 首页

历史 (tabBar) ← 自动刷新 useDidShow
我的  (tabBar) ← Phase 6 占位
```

关键规则：
- 跳转 tabBar 页面用 `Taro.switchTab`（报告→首页）
- 跳转普通页面用 `Taro.navigateTo`（首页→闯关、闯关→报告）
- `Taro.redirectTo` **不能**跳 tabBar 页（已知 bug，参考 docs/项目参考文件/Bug修复.md）

## 八、各页面功能说明

### 首页 (pages/index)

| 功能 | 实现方式 |
|------|---------|
| 主题输入框 | `<Textarea>` 组件，`onInput` 更新本地 state |
| 热门主题 tag | 点击 tag → 填充 topic，高亮选中状态 |
| 开始闯关按钮 | 写入 Zustand `topic`，`navigateTo` 到 quiz 页 |
| 统计数字 | `useEffect` + `useDidShow` 读取 `Taro.getStorageSync('quiz_history')` |

### 闯关页 (pages/quiz)

| 功能 | 实现方式 |
|------|---------|
| 环形进度 | CSS `conic-gradient(#4A9EDE Xdeg, #e8eff6 0deg)` 内联样式，外圆 + 内圆 hole |
| 单选选项 | `useQuizStore` 读取题目，点击触发 `submitAnswer` |
| 答后反馈 | `hasAnswered` state 控制显示，`result-panel.correct/.wrong` 样式 |
| 选项高亮 | `getOptClass(key)` 函数：correct（绿）/ wrong（红）/ default |
| 下一题/查看报告 | `hasAnswered` 控制按钮显示，最后一题点击 `navigateTo` report |

**冷启动处理**：若直接打开 quiz 页（store 为空），`useLoad` 会用 URL param topic + MOCK_QUESTIONS 初始化，确保页面可用。

### 报告页 (pages/report)

| 功能 | 实现方式 |
|------|---------|
| 大号分数环 | CSS `conic-gradient` + 计算 `pct * 3.6` 度数 |
| 评价文字 | pct ≥ 80 / ≥ 60 / < 60 三挡 |
| 薄弱知识点 | 从 `answers` 中过滤错误题目的 `tags` |
| 答题明细 | 遍历 `answers`，对比正确答案，显示 ✅/❌ |
| 保存历史 | `useEffect([], [])` 在首次渲染后写入 `quiz_history` localStorage |
| 再来一关 | `reset()` 清空 store，`switchTab` 返回首页 |

### 历史页 (pages/history)

- `useDidShow` 在每次 tab 切换时刷新数据
- 读取 `Taro.getStorageSync('quiz_history')` 渲染列表
- 空数据时显示 Empty State

### 我的页 (pages/profile)

Phase 6 占位页：展示登录入口和统计占位，点击登录按钮弹出 toast 提示。

## 十二、Phase 5 接口对接说明

Phase 5 中前端需要改动以下位置（不影响 store 结构）：

```
store/quiz.ts ─ initSession()
  当前：直接传入 MOCK_QUESTIONS
  Phase 5：改为 API 响应数据（结构相同）

pages/quiz/index.tsx ─ useLoad()
  当前：questions.length === 0 时使用 mock
  Phase 5：改为 Taro.showLoading + POST /api/quiz/generate
           成功后调用 initSession(sessionId, questions)

pages/quiz/index.tsx ─ handleSelect()
  当前：本地判断正确答案（isCorrect: key === q.correctAnswer）
  Phase 5：可选择保留本地判断，或调用 POST /api/quiz/answer

pages/report/index.tsx ─ summaryText
  当前：规则生成的文字
  Phase 5：改为 POST /api/quiz/report 返回的 AI 生成内容
```
