## 二、每次启动流程

### Step 1 — 启动 MySQL

确认 MySQL 服务正在运行（Windows 服务管理器 / Navicat 可确认）：
- Host：`127.0.0.1:3306`
- 用户名：`root`，密码见根目录 `.env`
- 数据库：`ai_quiz`（首次需手动创建：`CREATE DATABASE ai_quiz;`）

### Step 2 — 执行数据库迁移（新机器首次 / 表结构变更后）

```bash
cd backend
.venv\Scripts\python -c "
import os; os.chdir(r'D:\Python全栈AI答题小程序\backend')
from alembic.config import Config
from alembic import command
cfg = Config(r'D:\Python全栈AI答题小程序\backend\alembic.ini')
cfg.set_main_option('script_location', r'D:\Python全栈AI答题小程序\backend\alembic')
command.upgrade(cfg, 'head')
print('upgrade ok')
"
```

### Step 3 — 启动后端

```bash
cd backend
.venv\Scripts\activate
python -m app.main
```

后端运行于 `http://localhost:8000`，访问 `http://localhost:8000/docs` 可查看 Swagger 接口文档。

### Step 4 — 编译前端

```bash
cd miniprogram
npm run dev:weapp
```

监听模式，每次修改代码后自动重新编译到 `dist/`。

### Step 5 — 微信开发者工具配置

打开微信开发者工具，**按以下步骤操作（每台新机器第一次需要配置）**：

1. **导入项目**
   - 点击左上角"+"或"导入项目"
   - **目录**：选择 `miniprogram/dist/`（不是 `miniprogram/` 根目录）
   - **AppID**：填入 `wx7209249c6f886361`（已写入 `project.config.json`，导入后自动填充）

2. **开启"不校验合法域名"**（⚠️ 必须，否则无法请求本地后端）
   - 工具栏 → **详情** → **本地设置** 标签页
   - 勾选：**不校验合法域名、web-view(业务域名)、TLS 版本以及 HTTPS 证书**

3. **基础库版本**（建议使用稳定版，不要用灰度）
   - 工具栏 → **详情** → **本地设置**
   - 基础库：选择 **非灰度的稳定版本**（如 3.7.x / 3.8.x），避免用 3.18.0（当前为灰度版，可能有兼容问题）

4. 点击工具栏**编译**或等待 `npm run dev:weapp` 生成新的 `dist/` 后自动刷新

## 三、已知配置问题 & 解决方案

### ❌ 错误：`__webpack_modules__[moduleId] is not a function`

**原因**：Taro 4.x 的 `prebundle` 功能使用 Webpack 5 Module Federation，通过 `wx["webpackJsonp"]` 异步加载远程模块。微信小程序运行环境要求模块同步可用，异步加载完成前访问模块会得到 `undefined` 而非函数。

**已修复**：`config/index.js` 中设置 `prebundle: { enable: false }`，改回同步打包模式。

```js
compiler: {
  type: 'webpack5',
  prebundle: { enable: false }   // ← 必须为 false
}
```

### ❌ 警告："正在使用灰度中的基础库 3.18.0 进行调试"

**原因**：微信开发者工具当前选用了灰度（Beta）基础库，行为可能与正式版有差异。

**解决**：详情 → 本地设置 → 基础库，改为正式稳定版本（如 3.7.14）。

### ❌ 网络请求失败：`request:fail`

**原因**：未勾选"不校验合法域名"，`http://localhost:8000` 被微信拦截。

**解决**：详情 → 本地设置 → 勾选"不校验合法域名"。

### ❌ 后端启动时 `alembic: command not found`（路径含中文时）

**原因**：Windows 中文路径导致 alembic CLI 无法找到 `alembic.ini`。

**解决**：通过 Python 脚本调用 Alembic（见 Step 2 命令）。

## 四、目录说明

```
miniprogram/dist/   ← 微信开发者工具导入此目录（不是 miniprogram/）
miniprogram/src/    ← 源码，npm run dev:weapp 监听此目录
backend/app/        ← FastAPI 后端代码
backend/.env        ← 后端配置（不提交 Git）
.env                ← 全局配置（MySQL / DeepSeek Key 等，不提交 Git）
```

## 五、快速排查

| 现象 | 排查方向 |
|------|---------|
| 开发者工具白屏 | 确认导入的是 `dist/` 目录；确认 `npm run dev:weapp` 在运行 |
| `__webpack_modules__[moduleId] is not a function` | `config/index.js` 中 `prebundle.enable` 是否为 `false` |
| 点击"开始闯关"无反应 | 确认"不校验合法域名"已勾选；确认后端 `python -m app.main` 在运行 |
| 后端 500 错误 | 检查 `.env` 中 DeepSeek Key 是否正确；查看后端终端日志 |
| 数据库连接失败 | 确认 MySQL 服务已启动；确认 `.env` 中密码正确 |
