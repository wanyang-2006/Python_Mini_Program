## 二、完整启动流程

### Step 1 — 确认 MySQL 已运行

MySQL 8.0 通常随 Windows 开机自启。验证：

```bash
mysql -u root -p780801 -e "SHOW TABLES IN ai_quiz;"
```

应看到 `questions`、`quiz_sessions`、`reports` 三张表。若表不存在，运行迁移：

```bash
cd backend
.venv\Scripts\python -c "
import os; os.chdir('D:/Python全栈AI答题小程序/backend')
from alembic.config import Config
from alembic import command
cfg = Config('alembic.ini')
cfg.set_main_option('script_location', 'alembic')
command.upgrade(cfg, 'head')
print('OK')
"
```

### Step 2 — 启动 FastAPI 后端

```bash
cd D:\Python全栈AI答题小程序\backend
.venv\Scripts\uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

或双击根目录下的 `start_backend.bat`。

验证：浏览器访问 `http://localhost:8000/docs` 可看到 Swagger 文档。

### Step 3 — 编译前端（开发模式，可选 --watch）

```bash
cd D:\Python全栈AI答题小程序\miniprogram
npm run dev:weapp
```

监听模式会在每次保存源文件时自动重新编译到 `dist/`。如只需一次编译，用 `npm run build:weapp`。

### Step 4 — 微信开发者工具配置

1. 打开微信开发者工具 → **导入项目**
2. 目录选择 `D:\Python全栈AI答题小程序\miniprogram\dist\`
3. AppID 填写 `wx7209249c6f886361`（已在 `project.config.json` 中配置）
4. **关键**：工具栏 → **设置 → 项目设置** → 勾选"不校验合法域名、web-view(业务域名)、TLS 版本以及 HTTPS 证书"

> 此项不勾选，所有 `http://localhost:8000` 请求都会被拦截，出现 `net::ERR_CONNECTION_REFUSED` 或"工具未校验合法域名"警告。

## 三、后端接口说明（Phase 5 完整版）

**Base URL**：`http://localhost:8000`

**API 文档**：`http://localhost:8000/docs`（Swagger UI，可在线测试）

---

### 接口 1：生成题库

```
POST /api/quiz/generate
```

**功能**：输入学习主题 → 调用 DeepSeek → 返回 5 道结构化题目 + 会话 ID

**请求体**：
```json
{
  "topic": "Python 基础语法",
  "question_count": 5
}
```

**响应**：
```json
{
  "session_id": 3,
  "title": "Python 基础语法",
  "summary": "本次题库涵盖变量命名、数据类型等核心知识",
  "questions": [
    {
      "id": "q1",
      "type": "single",
      "stem": "以下哪个是 Python 合法的变量名？",
      "options": [
        {"key": "A", "text": "_my_var"},
        {"key": "B", "text": "1abc"},
        {"key": "C", "text": "my-var"},
        {"key": "D", "text": "class"}
      ],
      "answer": ["A"],
      "explanation": "Python 变量名须以字母或下划线开头...",
      "knowledge_point": "变量命名",
      "difficulty": "easy"
    }
    // ...共 5 道
  ]
}
```

**题型分布**（5 题）：单选 ≥ 2 题、判断 ≥ 1 题、剩余为单选或多选。

**前端调用时机**：首页点击"开始闯关"按钮。

---

### 接口 2：提交答案

```
POST /api/quiz/answer
```

**功能**：前端每选一道题后调用，后端校验正误、存库，并返回正确答案和讲解。

**请求体**：
```json
{
  "session_id": 3,
  "seq": 1,
  "user_answer": ["A"]
}
```

> `seq` = 题目序号（1-N），前端不需要知道数据库 `question.id`。

**响应**：
```json
{
  "is_correct": true,
  "correct_answer": ["A"],
  "explanation": "Python 变量名须以字母或下划线开头..."
}
```

**前端调用时机**：用户选择任意选项后立即调用（单选/判断自动提交）。

---

### 接口 3：生成学习报告

```
POST /api/quiz/report
```

**功能**：5 题全部作答后，调用 DeepSeek 生成个性化知识总结和学习建议，存入 reports 表（幂等：重复调用返回同一份报告）。

**请求体**：
```json
{
  "session_id": 3
}
```

**响应**：
```json
{
  "session_id": 3,
  "topic": "Python 基础语法",
  "title": "Python 基础语法",
  "summary": "围绕 Python 基础语法共作答 5 题，正确率 80%...",
  "suggestions": "建议重点复习变量命名规则和数据类型不可变性...",
  "weak_points": ["变量命名", "数据类型"],
  "correct_rate": 80,
  "total_questions": 5,
  "correct_count": 4
}
```

**前端调用时机**：报告页 `useEffect` 挂载时调用。

---

### 接口 4：历史会话列表

```
GET /api/quiz/sessions
```

**功能**：返回最近 50 条答题会话摘要，按时间倒序（MVP 阶段不过滤用户，Phase 6 加 user_id 过滤）。

**响应**：
```json
[
  {
    "id": 3,
    "topic": "Python 基础语法",
    "status": "done",
    "correct_rate": 80,
    "total_questions": 5,
    "created_at": "2026-11-14 04:56"
  }
]
```

**前端调用时机**：历史页 `useDidShow`（每次切换到历史 tab 时刷新）。

---

### 接口 5：健康检查

```
GET /health
```

**响应**：`{"status": "ok", "message": "AI答题闯关后端运行正常"}`

## 四、题型说明

| `type` 值 | 中文 | 选项格式 | 答案格式 |
|----------|------|---------|---------|
| `single` | 单选题 | `[{key: "A"...D}, ...]` | `["A"]` |
| `multiple` | 多选题 | `[{key: "A"...D}, ...]` | `["A", "B"]` |
| `judge` | 判断题 | `[{key: "对"}, {key: "错"}]` | `["对"]` 或 `["错"]` |

## 五、核心数据流（MVP）

```
用户输入主题
    ↓
POST /api/quiz/generate
    ├─ LangChain Prompt → DeepSeek
    ├─ 保存 QuizSession + Questions → MySQL
    └─ 返回 session_id + 5 道题

逐题作答（每题）
    ↓
POST /api/quiz/answer  (session_id + seq + user_answer)
    ├─ 按 seq 查出 Question
    ├─ 对比答案，写入 is_correct + user_answer_json
    └─ 返回 is_correct + correct_answer + explanation

5 题完成
    ↓
POST /api/quiz/report  (session_id)
    ├─ 聚合答题结果，计算 correct_rate + weak_points
    ├─ LangChain Prompt → DeepSeek → AI 个性化总结
    ├─ 保存 Report → MySQL
    ├─ 更新 QuizSession.status = "done"
    └─ 返回 summary + suggestions + correct_rate

历史页
    ↓
GET /api/quiz/sessions
    └─ 查询 QuizSession + Report → 返回摘要列表
```

## 六、错误码规范

| HTTP 状态码 | 触发场景 |
|-----------|---------|
| 200 | 正常 |
| 422 | 请求参数校验失败（Pydantic，如空主题、题数超限）|
| 404 | 资源不存在（session_id / seq 找不到）|
| 500 | 后端内部错误（DeepSeek 调用失败等，含 `detail` 字段说明原因）|

---

## 七、常见问题排查

| 现象 | 原因 | 解决 |
|------|------|------|
| `net::ERR_CONNECTION_REFUSED` | 后端服务未启动 | 运行 `start_backend.bat` 或 uvicorn 命令 |
| "工具未校验合法域名" | 开发工具设置未开启 | 设置 → 项目设置 → 勾选"不校验" |
| 500 题库生成失败 | DeepSeek Key 失效或余额不足 | 检查 `.env` 中 `DEEPSEEK_API_KEY` |
| 500 数据库连接失败 | MySQL 未启动 | 检查 MySQL 服务是否运行 |
| 答题后无讲解反馈 | 前端网络请求失败降级 | 检查后端是否运行，Console 查看错误 |
